# CODE/CLASH

**Ideas Assemble.**

A website for CODE/CLASH, a proposed 12-hour student hackathon presented by Bit Brothers at Towson University.

[Visit the website](https://codeclashtu.com/)

## Features

- Responsive, comic-inspired design with rotating winner and project spotlights
- Event information, participant roles, schedule, and FAQ
- Application form and public team board
- Organizer dashboard for application review and team management

## Built with

HTML, CSS, JavaScript, Supabase, and GitHub Pages.

## Local preview

Run from the project folder:

```bash
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/).
